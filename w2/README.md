# Week 2 - Learning about Graphics Programming

This week, we will finally delve into actual graphics programming.

We will first review last week's project and see how it really works under the hood in relation to graphics programming. 

After that, we will have a general overview of the graphics pipeline, and then we will try writing our own shader in GLSL.

# Prerequisites

- Complete the project from last week(w1)
    - Please make sure you're familiar with Rust at this point, by completing the Rustlings tutorial & last week's project in rust code. Next week we will be diving into some heavy rust programming.
- Basic understanding of how the code you write is executed on hardware
- Some basic mathematical knowledge: Trignometry, Calculus, Linear Algebra.
