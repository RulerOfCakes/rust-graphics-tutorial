# Week 3 - Ray Tracing

This week, we try out some ray tracing on the GPU.

After reviewing our last week's material once again and doing the last exercises, we will create another shader that will render a simple scene using ray tracing.

# Prerequisites

- Complete the project from last week(w2)
    - We will continue using Shadertoy this week as well, so make sure you have an account there.
- Some basic mathematical knowledge
